# AdventureWorks Sales Analytics Dashboard | Power BI

![Power BI Dashboard](https://github.com/yourgithub/AdventureWorks-PowerBI-Dashboard/blob/main/screenshots/dashboard-main.png)

An interactive **Power BI Sales Performance Dashboard** built to analyze AdventureWorks Bike Shop's sales, profitability, customer behavior, and product performance using the AdventureWorks dataset from Kaggle.

---

## 📊 Project Overview

This project demonstrates end-to-end **Business Intelligence and Data Visualization** skills by transforming raw sales data into actionable business insights. The dashboard provides a 360-degree view of revenue trends, geographic performance, product analytics, and customer segmentation.

### Key Business Metrics (2020–2022)
- **Total Revenue**: $24.9 Million
- **Total Profit**: $10.5 Million  
- **Total Orders**: 25.2K
- **Return Rate**: 2.2%

---

## ✨ Key Features

- **Revenue Trend Analysis**: Interactive line chart showing monthly revenue growth with forecasting elements
- **Geographic Performance**: World map visualization highlighting sales across **North America**, **Europe**, and **Pacific** regions
- **Product Performance**: Top 10 products, category-wise orders (Bikes, Accessories, Clothing), and return analysis
- **Customer Analytics**: 
  - 17.4K unique customers
  - $1,431 Average Revenue Per Customer
  - Segmentation by Income Level and Occupation
- **KPI Cards & Gauges**: Real-time performance tracking with targets
- **Deep Dive Analysis**: Product-level profitability with price adjustment simulation

---

## 🛠️ Technologies Used

- **Power BI Desktop** (Data Modeling, DAX, Power Query)
- **DAX** (Advanced Measures & Calculations)
- **Data Visualization** & **Interactive Dashboards**
- **Kaggle Dataset**: AdventureWorks Cycles
